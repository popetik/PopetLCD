Лёгкий драйвер HD44780 AVR, без классов с прямым доступом к портам.

# Зачем?

Стандартная библиотека LiquidCrystal удобная, но крайне тяжела: пример с Hello World занимает 1.9~ кб flash. PopetLCD делает то же самое за 800~ байт, потому что:

- работа напрямую с регистрами AVR, никакого DigitalWrite/pinMode
- нет класса и объектов - просто функции
- нет поддержки которая тебе, скорее всего не понадобиться прямо сейчас

Плата за это:

- пины жестко зашиты
- только AVR(Новые AVR Dx не поддерживаются)
- вывод чисел только в ХХ.ХХ формате

Если гибкость важнее веса прошивки - используй LiquidCrystal, если у тебя условная Atmega8 или крайне мало памяти и тебе всеравно на эти минусы, то вот для чего эта библиотека.

# Схема подключения

```
  Микроконтроллер PD4 > D4 дисплей(D4 на ардуино)
 	Микроконтроллер PD5 > D5 дисплей(D5 на ардуино)
 	Микроконтроллер PD6 > D6 дисплей(D6 на ардуино)
 	Микроконтроллер PD7 > D7 дисплей(D7 на ардуино)
 	Микроконтроллер PB0 > RS дисплей(D8 на ардуино) - пин RS
 	Микроконтроллер PB1 > E дисплей(D9 на ардуино) - пин Е
 	Пин дисплея RW подключаем к GND схемы
```

# Быстрый старт

	1. LCD_init()
	2. LCD_print()

# Таблица функций

	LCD_command(command_data, Is_RS) -- command_data вводим НЕХ команду, где Is_RS вводим ноль если это команда и единицу если это данные/символ
	LCD_nibble(nibble) -- функция отправки старшего полубайта
	LCD_init() -- функция инициализации, переводит дисплей в 4 бит режим, также очищает и возвращает курсор домой, после инициализации не обезательно прописывать LCD_setCursor(0, 0)
	LCD_clear() -- функция очистки дисплея, также возвращает курсор на начальные координаты
	LCD_data() -- функция вывода 1 символа
	LCD_setCursor(col, row) -- задает координаты курсора, где col это Х, где row это У
	LCD_print() -- выводит текст в скобках
	LCD_printNum(n) -- выводит целое число (uint16_t) на дисплей
	LCD_printInt(n) -- выводит число в формате XX.XX, где n — значение, умноженное на 100 (например, 1255 выведет 12.55)

# Замер веса - Использовал Arduino ide 2.3.10 на ардуино нано, результат:
Пустой скетч - 444 байт
PopetLCD.h примером Hello, World! - 806 байт(с учетом 444 байта пустого скетча), итого 362 байт
пример моего кода:

```
  void setup() {
    LCD_init();
    LCD_print("Hello, World!");
  }
```

результат получен в моих условиях компиляции и может отличаться от версии компилятора, Arduino core и используемого кода.
